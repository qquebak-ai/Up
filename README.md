# UPGRADER — демо-апгрейдер скинов CS2

Одностраничный сайт в стиле сервисов апгрейда скинов (аналог интерфейса `upgrader.pro/cis`).
Полностью статический: HTML + CSS + ванильный JavaScript, без сборки, зависимостей и бэкенда.

> **Важно:** это учебно-демонстрационный проект. Баланс, предметы и цены — виртуальные и хранятся
> только в `localStorage` браузера. Реальных платежей, вывода и связи со Steam здесь нет.
> Проект не связан с Valve Corporation.

## Возможности

- **Апгрейдер** — слот своего предмета, слот желаемого, круговой барабан с зоной выигрыша и анимацией стрелки.
- **Множители** ×1.5 … ×20 — автоподбор цели по стоимости текущего предмета.
- **Прозрачная формула шанса:** `(цена вашего / цена желаемого) × 0.92`, ограничение 1…92%.
- **Магазин** — поиск, сортировка, фильтры по редкости (цвета редкостей как в CS).
- **Инвентарь** — покупка, продажа поштучно и «продать всё», оценка стоимости.
- **Live-лента** апгрейдов, счётчики онлайна, окно результата, тосты.
- **Адаптивность** от 360px, бургер-меню, подсветка активного пункта навигации при скролле.
- **Графика без внешних ассетов** — силуэты оружия нарисованы инлайновым SVG с градиентом по редкости.

## Запуск

Достаточно открыть `index.html` в браузере. Либо поднять локальный сервер:

```bash
npx http-server . -p 8080
# http://localhost:8080
```

## Деплой на Vercel

Проект статический, шага сборки нет — Vercel отдаёт файлы как есть.

**Через интерфейс:** [vercel.com/new](https://vercel.com/new) → Import Git Repository → выбрать этот
репозиторий → Framework Preset: **Other**, Build Command и Output Directory оставить пустыми → Deploy.

**Через CLI:**

```bash
npm i -g vercel
vercel login
vercel --prod
```

Настройки заголовков и кэширования лежат в `vercel.json`.

## Структура

```
index.html              разметка всех секций и модальных окон
assets/css/style.css    тема, компоненты, адаптив
assets/js/data.js       каталог предметов, редкости, множители, ники для ленты
assets/js/weapons.js    SVG-силуэты оружия и рендер «картинки» предмета
assets/js/app.js        состояние, расчёт шанса, барабан, магазин, инвентарь
```

## Как настроить

- **Предметы и цены** — массив `ITEMS` в `assets/js/data.js` (`type` выбирает силуэт из `WEAPON_SHAPES`).
- **Комиссия и лимиты шанса** — константы `HOUSE_EDGE`, `MAX_CHANCE`, `MIN_CHANCE` в `assets/js/app.js`.
- **Стартовый баланс и инвентарь** — `START_BALANCE` и `STARTER_INVENTORY`.
- **Палитра** — CSS-переменные в `:root` (`assets/css/style.css`).

## Ответственная игра

Механика апгрейда математически убыточна: ожидаемая отдача — 92% от ставки.
Материал носит демонстрационный характер и предназначен для аудитории 18+.
