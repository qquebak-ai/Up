# NEON FORGE — демо-кузница скинов CS2

Одностраничный сайт в эстетике futuristic cyber-tech: пользователь загружает предмет CS2 в
энергетическое ядро и пробует пересобрать его в более дорогой. Полностью статический —
HTML + CSS + ванильный JavaScript, без сборки, зависимостей и бэкенда.

> **Важно:** это учебно-демонстрационный проект. Баланс и хранилище виртуальные и живут только
> в `localStorage` браузера; платежей, вывода и связи с аккаунтом Steam нет. Настоящие здесь лишь
> витринные данные: названия, цены и изображения предметов взяты с торговой площадки Steam.
> Изображения — собственность Valve Corporation, проект с ней не связан.

## Что внутри

- **Forge Core** — ядро с вращающимися кольцами, насечками и частицами на canvas; дуга кольца
  показывает шанс, маркер останавливается внутри неё или снаружи.
- **Фазы запуска** SCANNING → CALCULATING → FORGING → RESONANCE → RESULT с индикатором прогресса;
  успех — предмет проявляется из свечения, провал — ядро схлопывается (`CORE COLLAPSED`).
- **Пресеты шанса** 75 / 50 / 35 % — под выбранный шанс подбирается предмет подходящей цены;
  любую другую цель можно взять в маркете.
- **Forge Level** — уровень растёт с каждым запуском (+1 за попытку, +3 за успех), прогресс виден в шапке.
- **Карточки-артефакты**: изображение, класс редкости, износ, цена, `INSPECT`; при наведении —
  приближение оружия и сканирующая линия.
- **Отдельные страницы**: `market.html`, `profile.html`, `inventory.html`, `battles.html`,
  `contracts.html`, `protocol.html`. На главной остаётся только ядро.
- **Профиль** открывается по аватару в шапке: уровень кузницы, статистика запусков,
  лучший результат, телеметрия и live activity.
- Шапка липкая на всех страницах и остаётся на виду при прокрутке.
- Мобильная раскладка: баланс в шапке → предмет → ядро → шанс → цель → большая кнопка FORGE.

## Честность механики

```
chance = (цена входа / цена цели) x 0.92, предел 1...92%
```

Комиссия площадки — 8%. Ожидаемая отдача 92% означает, что механика убыточна на дистанции;
об этом прямо сказано в разделе Protocol и в футере.

## Запуск

Откройте `index.html` в браузере либо поднимите статический сервер:

```bash
npx http-server . -p 8080
```

## Структура

```
index.html              только Forge Core
market.html             витрина предметов
profile.html            профиль оператора: уровень, статистика, телеметрия
inventory.html          хранилище
battles.html            PvP-режимы
contracts.html          контракты
protocol.html           формула шанса и честность механики
assets/css/style.css    палитра, HUD-компоненты, адаптив
assets/js/data.js       каталог предметов, классы редкости, пресеты шанса
assets/js/weapons.js    подключение картинок Steam и запасные SVG-силуэты
assets/js/app.js        состояние, расчёт шанса, фазы ковки, частицы, витрины
```

> Сборки у проекта нет, поэтому шапка и футер продублированы в каждом файле —
> при правке навигации нужно пройтись по всем страницам.

## Настройка

- **Предметы и цены** — массив `ITEMS` в `assets/js/data.js`: `price` в центах, `icon` — токен
  картинки на CDN Steam, `type` выбирает запасной силуэт.
- **Комиссия и пределы шанса** — `HOUSE_EDGE`, `MAX_CHANCE`, `MIN_CHANCE` в `assets/js/app.js`.
- **Длительность фаз** — массив `PHASES` там же.
- **Палитра** — CSS-переменные в `:root`.

## Деплой на Vercel

Проект статический, шага сборки нет.

**Через интерфейс:** [vercel.com/new](https://vercel.com/new) -> Import Git Repository -> Framework Preset **Other**,
Build Command и Output Directory оставить пустыми -> Deploy.

**Через CLI:**

```bash
npm i -g vercel
vercel login
vercel --prod
```

Заголовки, `cleanUrls` и редирект со старого `/shop` на `/market` лежат в `vercel.json`.

## Поведение на телефоне

- Ширина документа равна ширине экрана — горизонтальной прокрутки нет (проверено на 320/360/390px).
- Масштабирование отключено: `user-scalable=no`, `touch-action: pan-y` и перехват жестов в JS.
- Ориентация: `portrait` в манифесте, попытка `screen.orientation.lock()` и заглушка «Поверните телефон».
- Обновление страницы — жестом «потянуть вниз» в самом верху.
- Учтены вырезы экрана через `env(safe-area-inset-*)`.
