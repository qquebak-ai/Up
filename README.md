# UPGRADER — демо-апгрейдер скинов CS2

Одностраничный сайт в стиле сервисов апгрейда скинов (аналог интерфейса `upgrader.pro/cis`).
Полностью статический: HTML + CSS + ванильный JavaScript, без сборки, зависимостей и бэкенда.

> **Важно:** это учебно-демонстрационный проект. Баланс и инвентарь виртуальные и хранятся только
> в `localStorage` браузера; реальных платежей, вывода и связи с аккаунтом Steam нет.
> Настоящие в проекте только витринные данные: названия, цены и изображения предметов взяты
> с торговой площадки Steam. Изображения — собственность Valve Corporation, проект с ней не связан.

## Возможности

- **Апгрейдер** — слот своего предмета, слот желаемого, круговой барабан с зоной выигрыша и анимацией стрелки.
- **Множители** ×1.5 … ×20 — автоподбор цели по стоимости текущего предмета.
- **Прозрачная формула шанса:** `(цена вашего / цена желаемого) × 0.92`, ограничение 1…92%.
- **Магазин** — поиск, сортировка, фильтры по редкости (цвета редкостей как в CS).
- **Инвентарь** — покупка, продажа поштучно и «продать всё», оценка стоимости.
- **Live-лента** апгрейдов, счётчики онлайна, окно результата, тосты.
- **Адаптивность** от 360px, бургер-меню, подсветка активного пункта навигации при скролле.
- **Настоящие предметы** — названия, износ, цены и картинки взяты с витрины Steam Community Market (CS2, appid 730).
  Каталог зафиксирован снимком в `assets/js/data.js`, картинки грузятся с CDN Steam; если картинка не открылась,
  подставляется нарисованный SVG-силуэт из `weapons.js`, и вёрстка не ломается.

## Запуск

Достаточно открыть `index.html` в браузере. Либо поднять локальный сервер:

```bash
npx http-server . -p 8080
# http://localhost:8080
```

## Поведение на телефоне

- Ширина документа равна ширине экрана — горизонтальной прокрутки и обрезки нет (проверено на 320/360/390px).
  Горизонтально скроллятся только ленты, где это задумано (`.feed__row`).
- Масштабирование отключено: `user-scalable=no` в meta, `touch-action: pan-y` в CSS и перехват
  жестов `gesturestart`/пинча/двойного тапа в JS (iOS игнорирует одну лишь meta-директиву).
- Ориентация: `"orientation": "portrait"` в `manifest.webmanifest` и попытка `screen.orientation.lock()`.
  В обычной вкладке браузера API блокировки недоступно, поэтому в альбомной ориентации телефона
  показывается заглушка «Поверните телефон» (`.rotate`), на планшетах и десктопе она не появляется.
- Учтены вырезы экрана: `viewport-fit=cover` и отступы `env(safe-area-inset-*)`.

## Деплой на Vercel

Проект статический, шага сборки нет — Vercel отдаёт файлы как есть.

**Через интерфейс:** [vercel.com/new](https://vercel.com/new) → Import Git Repository → выбрать этот
репозиторий → Framework Preset: **Other**, Build Command и Output Directory оставить пустыми → Deploy.

**Через CLI:**

```bash
npm i -g vercel
vercel login
vercel --prod
```

Настройки заголовков и кэширования лежат в `vercel.json`.

## Структура

```
index.html              разметка всех секций и модальных окон
assets/css/style.css    тема, компоненты, адаптив
assets/js/data.js       каталог предметов, редкости, множители, ники для ленты
assets/js/weapons.js    SVG-силуэты оружия и рендер «картинки» предмета
assets/js/app.js        состояние, расчёт шанса, барабан, магазин, инвентарь
```

## Как настроить

- **Предметы и цены** — массив `ITEMS` в `assets/js/data.js`. `price` хранится в центах, `icon` — токен картинки
  на CDN Steam, `type` выбирает запасной силуэт из `WEAPON_SHAPES`. Обновить каталог можно, повторно сняв данные
  с `https://steamcommunity.com/market/search/render/?appid=730&norender=1` и пересобрав массив.
- **Комиссия и лимиты шанса** — константы `HOUSE_EDGE`, `MAX_CHANCE`, `MIN_CHANCE` в `assets/js/app.js`.
- **Стартовый баланс и инвентарь** — `START_BALANCE` (в центах) и `STARTER_INVENTORY`.
- **Палитра** — CSS-переменные в `:root` (`assets/css/style.css`).
